# 3D models

Drop optional detailed models here. The app works without them.

- `head.glb`: a plain mannequin head and neck, upright, facing forward. Shown
  under the hat in the "Worn" view. It is scaled so its width matches the head
  measurement, and its top is lined up with the top of the built-in head.

Record where each file came from and its licence below.

## Sources

- `bunny.glb`: generated with the Tripo API (image to model, 30,000 face limit,
  standard texture) from a reference photo of a toy bunny supplied by the app's
  owner. Used as a "finished look" reference for the example bunny design. The
  photo itself is not in the repository. Before sharing the app more widely,
  check the rights to the original photo and Tripo's licence for the output.
